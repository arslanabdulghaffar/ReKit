## Scope and design before application changes

synthetic recovery demonstration is separate. Block B builds one explicitly
synthetic evidence-to-kit case using the existing catalog, image/evidence APIs,
human commands, CP-SAT and transactional inventory. No authentic physical-return
evidence has been supplied and verified for this new case. ABO inputs and model
outputs will remain separate from synthetic kit stock.

The [canonical case design](../canonical-case.md) records provenance, economic
assumptions, touched modules and measurable acceptance before implementation.
The planned baseline compares complete feasible rebuild, liquidation and retention
decisions; a single labor-rate change tests sensitivity. A competing approval
must fail without double reservation. The case keeps the initial incorrect
revision assertion, additional image and human correction in immutable history.

After that API case passes, focused UI work will present previous/current human
assertions, original source navigation and kit lineage using existing read data.
No new dashboard, authority, database schema, external endpoint or optimization
engine is required. Version/source-association errors are the main UI risk;
tests must cover sparse global event sequences, supersession, new evidence,
missing/mismatched sources, roles and reserved/consumed restrictions.

The separate B3 package will freeze the existing twelve development listing
groups, preserve exact recorded outputs/original images and leave assessments
pending. It supplies review questions, not human judgments or an accuracy claim.

and 60 total labor minutes. Retention assumes $6/body and $2/adapter. Liquidation
assumes $80/5 minutes for the body return, $10/2 minutes and $15/3 minutes for
the adapter returns. Every component receives exactly one disposition; revision
B cannot enter the approved A kit. Retention is not subtracted twice.

Changing **only labor rate from $0.25 to $2.00/minute** changes the recommendation:
rebuild becomes $70.00, liquidation **$85.00 (selected)**, retention $16.00.

rebuild exceeds the complete liquidation alternative by $72.50; under changed
labor, liquidation exceeds rebuild by $15.00. These are calculated differences
between synthetic feasible scenarios, not realized revenue or customer savings.

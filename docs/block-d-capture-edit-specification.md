## Manual capture and microphone procedure

Use the existing NVIDIA stills for the immediate edit: a new inference is not
needed. OBS is installed at `C:\Program Files\obs-studio\bin\64bit\obs64.exe`.
Installation does not verify capture, microphone selection or recording quality.
The owner performs the following local steps; no recording is started here.

1. Create a fresh private folder under ignored `var/mission06-offline/`, for
   example `block-d-recording-owner-01`, outside cloud sync. Preserve source clips
   and project files. Record `git rev-parse HEAD` in private notes. Close unrelated
   applications and notifications; do not show terminals, token fields or `.secrets`.
2. Open OBS. Use **Profile → New** and **Scene Collection → New**, named
   `ReKit Block D`, to preserve existing settings. Select local recording only;
   do not configure streaming. In **Settings → Video**, use 1920×1080 base/output
   and 30 fps. In **Settings → Output**, use Simple mode, the private recording
   path and MKV recording. Do not install encoders/plugins or change GPU drivers.
3. In the dedicated scene, **Sources → + → Window Capture**. Select only the
   ReKit browser window once it exists; leave desktop/display capture disabled.
   In **Settings → Audio**, disable Desktop Audio and unused global microphones.
   Add **Audio Input Capture** and explicitly select the intended microphone,
   or leave audio disabled when recording narration separately. Use headphones.
4. Record a 15-second nonsensitive test. Say the opening sentence and check that
   the mixer peaks roughly between −12 and −6 dB without reaching red. Stop;
   open the saved file and listen. Confirm readable browser text, no unrelated
   windows, intelligible voice and no echo. If capture/mic selection fails, resolve
   it manually before a full take; the stills route remains available.
5. For canonical motion, run these existing commands in a private terminal:

   ```powershell
   Set-Location 'A:\hackathon\ReKit'
   .\.venv\Scripts\python.exe -B evaluation/run_demo.py --mode canonical-recovery --check
   .\.venv\Scripts\python.exe -B evaluation/run_demo.py --mode canonical-recovery --headed --slow-mo-ms 300 --hold-seconds 120
   ```

   Wait until automatic sign-in is complete and the workbench is visible, select
   that browser window in OBS and start recording. Never capture the login token,
   even masked. Automation may already have advanced: use a clearly marked intake
   still for missed opening states. Do not add a fabricated click sequence.
6. Let the replay finish without interaction. It performs evidence/correction,
   saved-plan comparison, reservation conflict, completion, source navigation and
   mobile checks. Use the final 120-second hold for deliberate lineage scrolling
   only after assertions finish. Stop recording before the hold expires. Manual
   navigation is extra footage, outside the automated acceptance assertions.
   Let the launcher clean up its own processes and temporary credentials.
7. Check the new run's `runner-result.json` and `acceptance-result.json` for
   success, no page/cleanup errors and removed temporary state/credentials.
   Retain original capture plus exact run path. The launcher makes screenshots
   and receipts, not a movie. Do not replace a failed replay with fabricated motion.
8. Record narration separately in the same private profile if preferred: disable
   browser audio, speak in short paragraph takes with a second of quiet at each
   end, and record take numbers privately. Measure the actual speaking duration
   and adjust pauses/cuts before changing source statements. Keep the AMD paragraph
   on its own track. No AI voice or cloud upload is needed.
9. In the owner's selected local editor, use a 1920×1080 timeline. Fit sources
   proportionally; use a context shot before tight crops of readable details.
   Full-page screenshots are too tall to shrink into legible text. Hold each
   important state 3–5 seconds; use direct cuts, quiet audio and consistent captions.
   Use a fresh export filename. If the editor needs MP4, OBS **File → Remux
   Recordings** can make an MP4 copy of MKV while preserving the source. Editor,
   audio quality and final format compatibility remain unverified owner setup.

Fresh product motion is optional and should be chosen only if it materially
improves the final demonstration. The existing [storyboard's procedure](block-c-recording-storyboard.md#exact-manual-motion-and-narration-actions)
